# ShopScreen Documentation

## Overview
ShopScreen is the main shop UI, handling shop tabs, purchases, gifting, and social features. Includes onboarding, gamification, and accessibility enhancements.

## Props
None (screen-level component, uses hooks and context).

## Features
- Shop tabs (featured, seasonal, stubs for arena/raid/guild/faction)
- Purchase and gift flows
- Friend and invite modals
- Onboarding walkthrough
- Gamification bar
- Error/loading handling
- Accessibility and i18n
- Analytics and Sentry integration

## Usage
```
<ShopScreen />
```
