
# Contributing Guidelines for Poseidon

Thank you for contributing to the Poseidon backend! To keep our documentation and codebase high quality and up to date, please follow these guidelines:

## Documentation

- All new features, APIs, and endpoints must include documentation updates.
- API changes should be reflected in `src/models` and `src/types` docs.
- Run documentation generators before submitting a PR.

## Code

- Follow lint, format, and type-check rules (see root README).
- Write clear, descriptive commit messages.
- Add or update tests for all new features and bug fixes.

## Pull Requests

- Link related issues in your PR description.
- Ensure all CI checks pass before requesting review.
- PRs missing required documentation will not be merged.
