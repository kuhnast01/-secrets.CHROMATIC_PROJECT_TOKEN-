# Galaxy Ascendant — Client (demo)

This is a minimal React + Vite + TypeScript demo client for the Galaxy Ascendant API.

## Run
- Install: `npm install`
- Dev: `npm run dev` (opens at http://localhost:5173)
- API base URL: `VITE_API_BASE_URL` in `.env` (default `http://localhost:4000`)

Pages: Home (health), Player, Fleet, Combat — example fetch calls to the backend.
