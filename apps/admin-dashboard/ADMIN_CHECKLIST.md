# Admin Dashboard Checklist

This checklist is designed for easy onboarding and operation by non-technical users (e.g., high school or college students running the admin dashboard).

## Getting Started
- [x] Install dependencies: `pnpm install`
- [x] Start the dashboard: `pnpm start` (from `apps/admin-dashboard`)
- [ ] Log in/out as admin

## User Management
- [ ] View user list (search, filter, sort)
- [ ] Add new users
- [ ] Edit user details
- [ ] Delete users
- [ ] Import/export users (CSV)
- [ ] Approve/ban users

## Shop Management
- [ ] View shop items
- [ ] Add/edit/remove shop items
- [ ] Import/export shop items (CSV)

## Analytics
- [ ] View dashboard metrics (users, sales, events)
- [ ] View charts (add more as needed)

## Security
- [ ] Review security settings (2FA, password policy, audit log)
- [ ] Role-based access control (RBAC)

## Support
- [ ] Access help/support link
- [ ] Read FAQ for common issues
- [ ] Know who to contact for tech support
