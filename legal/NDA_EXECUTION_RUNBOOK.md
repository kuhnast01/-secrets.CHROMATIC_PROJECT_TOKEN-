# NDA Execution Runbook

## Trigger
Use this process before giving any external party access to:
- Source code
- Internal architecture docs
- Non-public roadmap/commercial terms

## Steps
1. Create NDA draft from [NDA_TEMPLATE.md](NDA_TEMPLATE.md).
2. Populate legal names, signatory info, and effective date.
3. Route through counsel-approved template controls.
4. Send for signature via approved e-sign workflow.
5. Verify fully executed copy is archived.
6. Grant scoped access only after archive verification.

## Access guardrail
- No access before NDA status is `Executed`.
